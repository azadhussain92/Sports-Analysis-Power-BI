# Sports Sales Analysis Dashboard | Power BI

## Project Overview
This project analyzes sports sales performance using Microsoft Power BI. The interactive dashboard provides insights into monthly net sales, Year-to-Date (YTD) sales, product performance, regional sales, and brand-level performance.

## Key Insights
- **Monthly Net Sales:** Track monthly net sales trends.
- **Net Sales YTD by Sport:** Analyze Year-to-Date sales across different sports.
- **Product Performance:** Compare net sales by product performance type.
- **Regional Sales Analysis:** Evaluate YTD net sales across different regions.
- **Brand-Level Analysis:** Compare YTD net sales across brands.
- **Year-over-Year Comparison:** Compare YTD performance through 15 September with the same period in 2025.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization

## Dashboard Features
- Interactive charts and KPI cards
- Monthly sales trend analysis
- Sport, product, region, and brand-level breakdowns
- YTD sales tracking
- Year-over-year sales comparison

## Objective
To understand sports sales performance, identify sales trends, compare product and brand performance, and support data-driven business decisions.
